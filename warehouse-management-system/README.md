# **Simple Warehouse Management System**

REST APIs (built using Spring Boot) which provides managing depot stocks and transferring product stocks inter-depots by taking specified rules into consideration.

**TECHOLOGY STACK** 

- Java 8
- Spring Boot
- Swagger
- Apache Maven
- Spring Data JPA
- ModelMapper
- PostgreSQL
- IntelliJ IDEA
